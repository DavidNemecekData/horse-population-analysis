# Video Gallery: Data Storytelling with Manim

This directory contains the final rendered animations that narrate the story of the horse population evolution in the Czech Republic. The narrative is delivered through a "Text-on-Screen" storytelling approach, combined with dynamic mathematical visualizations.

## Video Versions

The project includes two versions of the final animation to suit different presentation needs:

### 1. horse_population_audio.mp4 (Full Production)
*   **Audio:** Includes a cinematic background music track to enhance the atmospheric narrative.

### 2. horse_population.mp4 (Clean Narrative)
*   **Audio:** No audio track.

---

## Production Pipeline

The creation of these videos involved a multi-stage technical workflow:

1.  **Core Animation (Manim):** The primary visual layer (axes, graph drawing, data counters, and text highlights) was programmatically generated using the **Manim (Mathematical Animation Engine)** in Python. The source code can be found in [notebooks/02_story.ipynb](../notebooks/02_story.ipynb).
2.  **Post-Production Assembly (DaVinci Resolve):** The individual scenes generated by Manim were imported and sequentially merged into a single continuous timeline. This unified sequence was first rendered to produce the silent `horse_population.mp4` version.
3.  **Audio Integration:** A royalty-free ambient track was subsequently layered onto the timeline. This final composition was then rendered as the `horse_population_audio.mp4` version.
